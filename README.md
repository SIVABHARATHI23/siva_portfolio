# siva_portfolio

A single-page personal developer portfolio built with React 19, Vite 8, and Tailwind CSS v4. Features a video hero, scroll-linked animations (Framer Motion), and AOS reveals.

## Tech Stack

- **React 19** + **Vite 8** (`@vitejs/plugin-react`)
- **Tailwind CSS v4** (`@tailwindcss/vite`, CSS-first config)
- **Framer Motion** — preloader, scroll-linked SVG paths, parallax
- **AOS** — scroll reveal animations

## Sections

`Preloader` → `Navbar` → `Hero` → `About` → `Services` → `Contact` → `Footer`

## Getting Started

```bash
npm install
npm run dev      # start dev server
npm run build    # production build
npm run preview  # preview the build
npm run lint     # run ESLint
```
